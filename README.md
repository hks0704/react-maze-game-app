# 🎮 maze-game-app

> React + TypeScript로 만든 미로찾기 게임

---

## 📌 프로젝트 소개

> 사용자가 미로를 탐색하며 목표 지점까지 도달하는 웹 게임입니다.
> React 상태 관리와 게임 로직 설계를 연습하기 위해 제작했습니다.

---

## 🛠️ 기술 스택

### Frontend

* React
* TypeScript
* Tailwind CSS

### 상태 관리

* useState

---

## ⚙️ 주요 기능

* 🧩 게임 시작 / 재시작
* 🎯 목표 지점 도달
* ⏱️ 타이머 기능
* 🧠 난이도 조절 (옵션)
* 🎮 키보드 입력 / 클릭 이동

---

## 🧱 프로젝트 구조

```bash
src/
├── components/     # UI 컴포넌트
├── hooks/          # 커스텀 훅
├── pages/          # 페이지 단위
├── utils/          # 게임 로직
├── types/          # 타입 정의
└── App.tsx
```

---

## 🧠 핵심 로직 설명

### 1. 상태 관리

```ts
const [playerPosition, setPlayerPosition] = useState({ x: 0, y: 0 });
```

### 2. 이동 로직

* 방향키 입력 → 좌표 변경
* 벽인지 체크 후 이동

### 3. 렌더링 구조

* 2차원 배열 기반 맵
* Cell 컴포넌트로 분리
